# Maple Leaf Rag 16秒・87音 単旋律のGame Boy変換レポート

## 入力と確認範囲

- 正本MIDI: `maple_leaf_rag_16bars_melody_bridge.mid`（ユーザー提供、作業用一時パスから読込み）
- SHA-256: `b009472e114c5527125c5a56cb58a01683cb7cd8d38b903ea0673a02044820a0`
- SMF format 1、PPQ 384、tempo 500000 µs/quarter = 120 BPM、拍子2/4。音符を持つtrackは1つで87音、同時発音・重複は0。
- MIDI最後のnote-offはtick 12288 = 16.000000秒。16小節であり、入力のピッチ・発音順は変更していない。
- 6.25〜7.375秒のbridgeはevent e30〜e38の9音。下表とUGE双方で全9音の音程・順序・rowを照合した。
- 旧8小節出力JSON/UGE/ROMは`assets/`には残っていなかった。一方、JSON→UGE→ASM→ROMの既存ツール群は利用可能だった。

## 変換方法とループ

- JSON Version 2、Pulse1 / CH1のみを使用。CH2、Wave、Noiseは無音。伴奏は追加していない。
- 各MIDI開始・終了時刻を最近傍1/60秒rowへ丸め（tieは後ろ側）、`tempo=1`（TicksPerRow=1）を設定。1 quarter = 30 rows、16秒 = 960 rows = 15 orders × 64 rows。UGEの全order循環で先頭へloopする。
- order境界を越える継続音の余分なretriggerを防ぐため、Version 2の`hold`を追加した。`hold`はNO_NOTE / Instrument 0 / effectなしの空cellを出力し、状態を変えずrowだけ進める。実休符は既存の`rest`→E00 note cutで表した。
- MIDIのinter-note休符10か所をUGEのE00 cut 10か所へ対応。loop境界で最終音を切るE00をrow 0にも置く。Human試聴で同音連打が長音のように聞こえたため、休符のない同音連打11境界にも次音開始rowの1 row前へE00を追加した。既存のMIDI休符は変更していない。
- 最終音はsource tick 12096–12288、UGE row 945–960。row 960でloopしrow 0を処理するため、発音が次周へ持ち越されない。冒頭は23 rows (=0.383333秒)無音。

## 同音連打の原因とアーティキュレーション調整

hUGEDriverを確認した結果、Pulse1の有効note行は同じ音高でも周波数を更新し、`play_ch1_note`からNR14のtrigger bitを書き込む。したがって再trigger自体は行われていた。Instrumentのhardware envelopeは`envelope_sweep: 0`で音量が自然減衰せず、同音の間に無音rowもなかったため、同じ高さの音が切れずに聞こえる状態だった。汎用converterやdriverの不具合ではなく、この曲のnote境界に短い無音を設けるデータ修正とした。

次の11境界で前音の発音時間を1 row短縮し、次音開始は動かさず、その直前rowでE00を処理する。1 rowはnominal 60 Hzで16.667 ms、Game Boy VBlank基準で約16.743 msである。この短縮はGB向けアーティキュレーション調整として意図したもので、MIDIのnote-offとの位置差は次表のとおり。

## tempoとタイミング誤差

- 60 Hz nominal基準では960 rows = 16.000000秒、tempoは120.000 BPMで理想値に一致。
- Game Boyの通常speed VBlank周波数を4,194,304 / (154×456) = 59.727500570 Hzとすると、1 row / VBlankの再生時間は 16.072998047 秒（16.000秒より +72.998 ms）。実効tempoは 119.455001 BPMで、120 BPMとの差は -0.544999 BPM（-0.4542%）。これは固定60 HzではなくGame Boy VBlankで更新することによるclock差。
- MIDI時刻からnominal 60 Hz rowへの量子化誤差（開始時刻）: min +0.000 ms、max +8.333 ms、最大絶対値 8.333 ms、平均絶対値 4.693 ms。
- アーティキュレーション調整前の終了時刻: min +0.000 ms、max +8.333 ms、最大絶対値 8.333 ms、平均絶対値 3.736 ms。調整後は上表の11音のみを1 row早くcutし、元MIDI note-offとの差は-8.333 msまたは-16.667 msとなる。
