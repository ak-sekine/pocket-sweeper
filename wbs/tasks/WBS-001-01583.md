# 目的

01580のCompositionStructureを共通timelineとして、physical channelへ固定されないbass logical layerをseed再現可能に生成する。
# 作業内容

root/chord-tone/passing/pedal/ostinato等のbass relationとpitch representationを分離して保持するpattern definition/instance/eventを実装する。harmony progressionは生成せずcaller-supplied referenceだけを検証する。CH3、Wave、Instrument、UGE、melody・伴奏・noise・SFXは扱わない。
# 入力

01579のGenerationContext、01580のCompositionStructure、01576のlogical layer model、一般音楽理論・wave bass調査、hardware/tool仕様。
# 成果物

`tools/bgm_generator.py`のlogical bass model/generator、`tests/test_bgm_generator.py`の再現性・検証テスト、`docs/generated-bass-layer.md`。
# 完了条件

同一context呼び出し順・同一structure・同一parameters/options・同一seedで同じbass layerを生成し、pattern/phrase/event/harmony reference、bass relation、pitch/rest排他、範囲、duration、overlap、serializationを機械検証できる。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Git履歴で、初回移行時の「CH3ベース」は旧WBS文言の引き継ぎであり、現行01576の`logical layer != physical channel`と一致しないことを確認したため、タイトルをbass logical layerへ整理した。bassは01581/01582を入力必須とせず、依存はGenerationContextを提供する01579とCompositionStructureを提供する01580に限定した。

`BassPatternDefinition`、`BassPatternInstance`、`BassEvent`、`BassLayer`を実装し、bass relationとpitch表現を分離した。harmony progressionは作らずcaller-supplied referenceだけを検証し、exact/relative offset variation、rest補完、single logical voice overlap検証を実装した。CH3 allocation、Wave/UGE、Human evaluationは未実施である。
