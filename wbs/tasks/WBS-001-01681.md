# 目的

現在方式のparameter tuningではない、根本的に異なる自動作曲アプローチの候補を調査する。

# 作業内容

既存楽曲・パブリックドメイン曲を基礎にした生成・編曲、MIDI等の中間表現、明示的な音楽理論、corpusからの構造抽出・学習、AI/LLM利用、人と自動処理の組み合わせ等を候補例として、候補を固定せず調査する。必要な場合は外部資料と出典を記録する。候補方式を採用決定しない。

# 入力

01680の技術基盤整理、既存の評価結果、evidence schema/workflow、関連する外部資料。

# 成果物

候補方式、根拠、前提、未確定事項を整理した調査文書。

# 完了条件

根本的な方式候補を複数の観点から調査し、出典・制約・未確定事項を記録する。

# 完了にしてはいけない条件

Codexが次に試す方式を選択した場合、または調査候補をproduction方式として実装した場合は完了にしない。

# 確認結果

既存方式のparameter tuningではない候補として、原曲・パブリックドメイン曲を基礎にした編曲、MIDI/MusicXML中間表現、明示的音楽構造モデル、corpus構造抽出、AI/LLM/生成モデル、Human+automationを並列に調査した。各候補について入力、処理、出力、4ch/JSON接続、Human範囲、再現性、provenance、license、未確定事項を記録し、方式の比較・順位付け・採用・実装は行っていない。

# 証跡

候補方式調査文書: `docs/generated-song-approach-investigation.md`。外部資料のURL、提供元、確認事実、調査日、未確定事項を記録した。
