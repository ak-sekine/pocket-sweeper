# 目的

評価用profileを既存JSON→UGE→ASM→ROM pipelineへ接続し、Human評価へ渡す複数候補を生成する。

# 作業内容

品質評価用profileを変更せず、事前に定めたseed集合`1, 5, 7`で候補を生成し、JSON/UGE/ASM/ROM、UGE structural validation、order alignment、RGBDS build、artifact hash、再現性を確認する。既存本体artifactを上書きしない。

# 入力

01674のprofile、01591 pipeline、明示的seed集合。

# 成果物

candidateごとのJSON、UGE、ASM、ROM、manifestと`docs/generated-song-quality-candidates.md`の検証記録。

# 完了条件

固定seed 1/5/7の全candidateでJSON/UGE/ASM/RGBDS ROM生成、UGE Song Version 6・order alignment・CH1〜CH4構造検証、seed対応・SHA-256・同一runのUGE/ROM対応・seed 1の再現性が記録される。Human試聴による選別は行わない。

# 完了にしてはいけない条件

Humanの聴感で候補を選別した場合、または失敗artifactを候補として扱った場合は完了にしない。

# 確認結果

quality_candidate_01〜03を生成。全candidateでJSON/UGE/ASM/RGBDS ROM生成とUGE構造検証に成功した。seed 1を同名で一時directoryへ再生成し、JSON/UGE/ASM/ROMのSHA-256一致を確認した。候補間の全artifact hashとmelody motif選択に差がある。Human試聴・音楽品質判定は未実施。

# 証跡

候補一覧・hash・UGE解析結果・RGBDS実行結果・再現性: `docs/generated-song-quality-candidates.md`。各candidateの詳細manifestは各artifact directoryの`*.manifest.json`。
