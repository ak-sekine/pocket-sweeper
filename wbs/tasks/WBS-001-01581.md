# 目的

01580のCompositionStructureを入力として、phrase境界と共通time grid上に、physical channelへ固定されない主旋律logical layerをseed再現可能に生成する。
# 作業内容

motif definition/instance、relative interval等の排他的なpitch relation、rest、duration、phrase reference、exact/relative offset variationを実装する。固定parametersとcandidate optionsを分離し、reference、範囲、重複、serializationを機械検証する。harmony・accompaniment・bass・noise・physical CH1は扱わない。
# 入力

01579のGenerationContext、01580のCompositionStructure、01576のlogical layer model、一般音楽理論・Game-BGMのmotif/variation調査、hardware/tool仕様。
# 成果物

`tools/bgm_generator.py`のlogical melody model/generator、`tests/test_bgm_generator.py`の再現性・検証テスト、`docs/generated-melody-layer.md`。
# 完了条件

同一context呼び出し順・同一structure・同一motif parameters/options・同一seedで同じlogical melodyを生成し、motif/phrase/event参照、pitch/rest排他、範囲、duration、overlap、serializationを検証できる。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Git履歴で、初回移行時の「CH1主旋律」は旧WBS文言の引き継ぎであり、現行01576の`logical layer != physical channel`と一致しないことを確認したため、タイトルをlogical layer表現へ整理した。01579のみの依存では01580のCompositionStructureを保証できないため、01580を明示依存へ追加した。

`MotifDefinition`、`MotifInstance`、`MelodyEvent`、`MelodyLayer`を実装し、exactとrelative interval offsetの最小variationを呼び出し側parameterとして扱った。CH1割当、absolute pitch解決、harmony・伴奏・bass・noise、UGE mappingは未実装である。Human evaluationは実施していない。
