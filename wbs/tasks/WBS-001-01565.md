# 目的

Instrument・Wave・Noise・effectについて、hUGETracker / UGE / hUGEDriver / Pocket Sweeper JSON変換の実際の表現範囲を確認し、自動生成・検証可能な境界として整理する。
# 作業内容

Instrument、Wave table、Noise Instrument、effectについて、hUGETracker・UGE・hUGEDriverの実仕様と実装上の表現範囲を調査する。21曲の使用傾向は品質根拠にしない。
# 入力

仕様・実装の出典、対応範囲、未対応事項。
# 成果物

`docs/huge-instrument-effect-capability-research.md` に、version・実装基準、各Instrument、Wave table、Noise、note/event、effect、層別対応表、JSON Version 2、JSON→UGE→hUGEDriver、parameter対応、Generator / Converter責務、Validation、Supported / Partial / Unsupported / Not verified、Human verification、未対応事項、後続方針を記録した。
# 完了条件

現在のSong Version 6 UGE、hUGEDriver、JSON Version 1/2、`json_to_uge.py`、UGE analyzer、テストを確認し、Pulse/Wave/Noise Instrument、note/pattern/order、effectの層別表現範囲を整理する。JSON直接入力、converter導出、driver内部処理、Unsupported、Not verifiedを分離し、自動生成・検証可能な境界を記録する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Song Version 6、リポジトリ内hUGEDriver、JSON Version 1/2、`json_to_uge.py`、`analyze_uge.py`、関連テストを確認した。Pulse/Wave/Noise Instrument、Wave table、note/rest/length、pattern/order、loop、hUGEDriver effect dispatchとJSON直接入力の差を整理した。hUGEDriverはeffect 0〜Fをdispatchするが、現行JSONのeffect入力はnullのみで、C/E/Bはconverter内部生成であることを確認した。UGE GUIの新規操作、最新版upstream差分、全effectのGUI互換性、試聴・実機・エミュレータ確認は未実施であり、Not verifiedとして記録した。21曲UGE素材は品質根拠に使用していない。旧目的文は現在の役割に合わせて修正した。
