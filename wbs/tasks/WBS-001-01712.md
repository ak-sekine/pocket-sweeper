# 目的

source BPMとruntimeのrow timingを混同せず、各stageのテンポ表現を比較する。

# 作業内容

source 120 BPM、PPQ、quantization grid、JSON/UGE TicksPerRow、hUGEDriver row進行、ROM想定実時間を数値化する。

# 入力

01708の修正版artifact、JSON/UGE analyzer、runtime仕様。

# 成果物

tempo diagnostic report。

# 完了条件

1拍・1row・patternの時間関係を明示し、BPMとTicksPerRowを別fieldで記録する。

# 完了にしてはいけない条件

format値だけで実時間再生やHuman評価を確定しない。

# 確認結果

承認済みsourceを再確認し、120 BPM、PPQ384、tempo event 1件を確認した。JSON/UGE/ASMのTicksPerRow 6と固定60 Hz runtimeから1 row=0.1秒を算出し、source 30-tick row=0.0390625秒およびselected eventのsource 121.75秒→runtime 3.9秒のtimeline repackingを別々に記録した。tempo値やpipelineは変更していない。

# 証跡

source tempo、runtime parameter、計算式、selected event mapping、未確認runtime項目を [tempo diagnostic report](../../docs/generated-pd-maple-leaf-rag-tempo-diagnostic.md) とmachine-readable diagnosticに記録した。
