# 目的

01579のseed付き生成基盤を使用し、後続の各logical layerが共有する曲構成・section・phrase・time grid・logical loop構造を再現可能に生成する。
# 作業内容

固定のstructure parametersと呼び出し側が与えるcandidate optionsを分離し、GenerationContextからseed付きでsection/phrase timelineとlogical loopを生成する。整数tick、参照整合性、連続timeline、none/full/range loopを検証し、決定的serializationを提供する。音符、layer内容、physical channel、UGE mappingは実装しない。
# 入力

01579の`GenerationContext`、01576のComposition/Logical timelineモデル、loop・Game-BGM・一般理論の調査、`docs/sound-spec.md`および`docs/json-format.md`。
# 成果物

`tools/bgm_generator.py`の構造model/generator、`tests/test_bgm_generator.py`の再現性・整合性テスト、`docs/generated-composition-structure.md`。
# 完了条件

同一seed/optionsで構造が再現し、time grid、section/phrase境界、ID/reference、none/full/range loopを機械検証できる。最終的な音楽parameterやphysical allocationを暗黙に決定しない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01579が`complete`であることを確認した。`StructureParameters`と`StructureGenerationOptions`を分離し、候補が空の場合はエラーとした。初版は整数tick、連続section/phrase、phrase境界range loopを構造model上の制約として採用したが、音楽的defaultや普遍的なphrase境界規則とはしていない。

`none`、`full`、`range`、不正grid/loop、candidate選択、deterministic `as_dict()`、section/phrase参照整合性を自動テストした。logical loopはUGE B effectと分離し、physical channel・音符・UGE mapping・SFX保証は未実装である。
