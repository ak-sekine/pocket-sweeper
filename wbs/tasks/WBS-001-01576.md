# 目的

melody・motif・rhythm・harmony・bass・accompaniment・noiseを論理layerとして独立管理し、共通時間軸、4ch allocation、loop、SFX一時欠損を検証できる制約付き表現を定義する。
# 作業内容

各層を独立管理しつつ、4ch、同期、音域、同時発音、loop、SFXによる一時的なchannel欠損を検証できる表現を定義する。21曲由来の固定パターンを前提にしない。
# 入力

ルール表現と検証項目の設計。
# 成果物

`docs/constrained-composition-layer-model.md` に、Composition model、Logical timeline/layer model、Physical allocationを分離したモデル、共通musical time grid、harmony/motif/melody/rhythm/bass/accompaniment/noise、optional/priority、skeleton、4ch capability、allocation、loop、JSON/UGE mapping、SFX preemption/degradation、rule_refs、validation stages、未確定事項を記録する。
# 完了条件

各層の依存関係と未確定事項を記録する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01572・01573・01574・01575が`complete`であることを確認した。layerとphysical channelを固定対応させず、論理layer、共通時間軸、harmony realization、allocation、tool mappingを分離した。`rule_refs`で01575のRule IDを参照できる構造を定義した。CH1/CH4 SFX占有とCH2/CH4欠損耐性方針の関係はconflict/open issueとして保留した。Human evaluation、generator実装、最終key/scale/tempo/meter/progression/allocationは未確定とした。
