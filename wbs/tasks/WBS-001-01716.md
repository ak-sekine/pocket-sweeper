# 概要

Human判断に従い、長さ・テンポ・リズム・音程/メロディを個別parameterとしてではなく、原曲の構造を保ったGame Boy向け縮約処理全体として再設計・検証する。具体方式は後続taskのevidenceを経て決定し、production採用は別途Humanが判断する。

# 配下の作業

- WBS-001-01717 改善後の統合編曲方式と保持条件を設計する
- WBS-001-01718 source timeline/measureを保持する縮約方式を実装する
- WBS-001-01719 melody/bass/harmony等の抽出と4ch割当を見直す
- WBS-001-01720 source BPMとruntime row timingの対応を設計する
- WBS-001-01721 統合方式の長さ・テンポ・リズム・音程を再検証する
- WBS-001-01722 統合方式のMaple Leaf Rag prototype ROMを再生成する
- WBS-001-01723 統合方式ROMをHumanがSameBoyで再試聴する
- WBS-001-01724 統合方式の実用性をHumanが再評価する

# 確認結果

machine上ではcross-measure local-row false collisionを0にし、ROMまで再生成した。Human試聴原文は「全く改善していません。」、実用性判断原文は「見直しが必要と判断します。」であり、音楽的改善は確認されなかった。原因は特定せず、次の見直し診断groupへ引き継ぐ。
