# 目的

MIDI event representationからROMまでを比較できるdiagnostic方式を設計する。

# 作業内容

note pitch、onset、duration、contour、同時発音、event count、omission、transformationをsource event ID付きで比較する境界と出力形式を定義する。

# 入力

01692〜01695のprototype、manifest、report、Human評価。

# 成果物

diagnostic仕様と比較対象・判定項目。

# 完了条件

各変換段階の入力・出力・比較可能なfield・loss分類を再現可能に定義する。

# 完了にしてはいけない条件

Human評価の原因を根拠なく特定しない。

# 確認結果

MIDI、parsed MIDI event、generated MusicXML、NormalizedScore、ArrangementPlan、JSON Version 2、UGE、ASM、ROM/runtimeの境界について、source event identity、共通event fields、stage固有fields、timing/pitch正規化、同時発音、role/channel、loss分類、contour、summary metrics、machine-readable report、determinism/provenance、64-row scopeを再現可能に定義した。JSON Version 2を診断情報のために変更せず、sidecar reportを使用する。実測比較と原因判定は01698以降へ残した。
