# 目的

01559で確認したGame Boy APUのハードウェア制約を、自動作曲器が守る生成ルール・検証条件として定義する。
# 作業内容

CH1〜CH4の音源特性、同時発音、pulse/wave/noise、duty、envelope、sweep、wave table、音域・音量・effectの実仕様を根拠として、生成時に保証できる制約を定義する。
# 入力

出典付きハードウェア制約表と生成時検証条件。
# 成果物

`docs/game-boy-hardware-composition-rules.md` を作成し、分類済みのルール表、CH1〜CH4、4ch、frequency/note、volume/envelope、duty/sweep、Wave table、Noise、SFX共存、機械検証条件を記録する。
# 完了条件

資料・実装の出典と、未確定事項を含むルール定義を記録する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

文書・実装を確認した。CH1〜CH4のhardware/tool条件、4ch以下・単一発音、値域、CH1専用sweep、CH3 Wave table、CH4 Noise note/NR43導出、volume/envelopeの層、SFX一時muteを分類して機械検証条件へ整理した。音楽的なchannel役割、適切な音域、noiseの聴感、SFX欠損耐性の未確定事項は確定ルールにしていない。01559が`complete`であることを確認済みで、人によるGUI・実機・試聴は本タスクの完了条件に不要と判断した。
# 証跡

`docs/game-boy-hardware-composition-rules.md` のルール一覧、各CH節、機械検証条件、未確定事項、後続WBS引き継ぎ。21曲UGEの多数派は品質根拠に使用していない。
