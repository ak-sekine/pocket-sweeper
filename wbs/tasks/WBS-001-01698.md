# 目的

MIDIからgenerated MusicXML、NormalizedScoreまでのnoteとtiming保存性を検証する。

# 作業内容

source eventと各中間表現のpitch、onset、duration、tempo、meter、event countを比較し、reconstructed/lost/unknownを実測で分類する。

# 入力

01693のsource MIDI、MusicXML、manifest、report、diagnostic設計。

# 成果物

MIDI/MusicXML/NormalizedScore比較結果。

# 完了条件

note/timing差分と未比較項目をsource event単位で記録する。

# 完了にしてはいけない条件

差分を音楽的原因と断定しない。

# 確認結果

承認済みMutopia MIDIをSHA-256検証し、source MIDI、parsed MIDI、generated MusicXML、NormalizedScoreをfull normalized source scopeで比較した。2566 note eventsが1対1でmappingされ、pitchは2566/2566 exact、durationは2566/2566 exact、onsetは981 exact・1585 mismatch・rounded 0だった。MusicXMLからNormalizedScoreはpitch/onset/durationとも2566/2566 exactだが、これは同一prototype parser由来の比較であり独立実装による検証ではない。tempo 500000 microseconds/quarterとmeter 2/4をsourceから再確認し、MusicXML/NormalizedScore側はRECONSTRUCTEDとして分類した。source event単位の差分、hash、rounding rule、deterministic再実行結果をdiagnostic JSON/Markdownへ記録した。差分をHuman評価の原因とは断定していない。
