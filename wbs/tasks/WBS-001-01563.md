# 目的

bassの音楽的役割とGame Boy wave channelの音源制約を接続し、CH3固定や具体patternを決めず、bass layerを生成・検証可能な条件として整理する。
# 作業内容

CH3のwave table特性、bassの音域・harmonyとの関係、ゲームBGMでのlayer設計を実仕様・出典に基づき調査する。フリー素材の使用傾向は品質根拠にしない。
# 入力

出典付きの調査記録と未確定事項。
# 成果物

`docs/game-boy-wave-bass-design-research.md` に、情報源、bassの役割、chord/harmony、bass pattern、CH3 hardware、waveform、register、rhythm、melody/accompaniment、4ch制約、SFX/layer欠落、自動生成分類、Pocket Sweeperへの適用、未確定事項、01564/01565への引き継ぎを記録した。
# 完了条件

信頼できる複数資料を確認し、bassとchord rootの関係、bass pattern候補、CH3 wave特性、waveform・register・rhythm・layer制約を整理する。Hardware-valid / Theoretical relationship / Musically-suitable、Hard constraint / Soft rule / Parameter / Human evaluationを分離し、CH3固定、waveform、octave、pattern、densityを根拠なく決定しない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Open Music Theory、University of Minnesota、University of Puget Sound、CMU、Pan Docsおよび既存仕様・実装を確認した。chord.rootとbass.noteの分離、root/chord tone/passing/pedal等の候補、CH3のwave table・output level・frequency・length・trigger・wave RAM制約、waveformのharmonic contentを整理した。聴感上のbass register、waveformの適否、density、layer欠落時の自然さはHuman evaluationとして分離した。試聴・実機・エミュレータ確認は未実施である。CH3=bass、具体waveform・octave・pattern・density、01564/01565の詳細は確定していない。21曲UGE素材は品質根拠に使用していない。旧目的文は現在の役割に合わせて修正した。
