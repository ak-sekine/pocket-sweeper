# 目的

01560で調査した一般音楽理論を、自動作曲器で利用できる生成ルール候補・parameter・検証条件として定義する。
# 作業内容

出典付き調査からscale/key、melody、motif、phrase、harmony、rhythm、cadence、bass、accompanimentの候補ルールを定義し、一般論をGame Boy・ゲームBGMへ適用する条件と未確定事項を明示する。
# 入力

出典付きルール定義。
# 成果物

`docs/general-music-theory-composition-rules.md` に、Theory relationship、Hard constraint、Soft rule、Parameter、Human evaluationを分類したルール一覧と、scale/key、melody、motif/phrase、repetition/variation、harmony、rhythm、cadence、bass、accompaniment、Game Boy/Game-BGM適用条件を記録する。
# 完了条件

各ルールの根拠・適用範囲・未確定事項を記録する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01560が`complete`であることを確認した。一般理論、Game-BGM由来の反復・variation、01572のGame Boy hardware/tool制約、Pocket Sweeper方針を区別してルール化した。scale-only、chord-tone-only、fixed-grid、exact-repeat等は選択mode内のHard constraint候補とし、step/leap、voice leading、cadence、density等はSoft rule候補とした。試聴・実機・エミュレータ確認は実施しておらず、品質判定はHuman evaluationへ残した。
# 証跡

`docs/general-music-theory-composition-rules.md` の出典一覧、分類済みルール表、各概念節、機械検証条件、Game Boy/Game-BGM適用条件、未確定事項、後続WBS引き継ぎ。21曲UGEの多数派は品質根拠に使用していない。
