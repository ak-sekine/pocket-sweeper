# 目的

既存UGEを作曲品質の根拠から除外し、UGE解析・形式多様性・回帰テスト・生成結果検証に利用できる範囲を定義する。
# 作業内容

21曲から作曲品質や自動作曲ルールを推論しない。必要な場合に限り、UGE解析の入力サンプル、形式の多様性、回帰テスト、生成器の検証データとして利用する範囲を定義する。人の試聴評価は別WBSで扱う。
# 入力

サンプル利用方針と検証対象項目。
# 成果物

`docs/uge-corpus-test-usage-policy.md` に、対象コーパスの数（36候補、25実ファイル、A判定21曲）、許可用途、禁止推論、analyzer観測値、raw cell、loop、channel、Instrument/effect、ライセンス境界、テスト分類、コーパス不在時の運用、01570/01572/01573との関係を記録する。
# 完了条件

作曲ルールの根拠から明確に除外した利用方針を記録する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01569が`complete`であることを確認した。既存UGEをparser input、format diversity、regression、edge-case discovery、生成UGEの構造比較へ利用し、作曲品質 evidence・default parameter推定・quality scoreには利用しない方針を定義した。21曲はA判定集合（25実ファイルから第三者作品由来4曲を除く）として明確化し、36曲候補・25実ファイル・11曲未確認と区別した。外部UGE、GUI、試聴、実機確認は追加していない。
# 証跡

`docs/uge-corpus-test-usage-policy.md` の利用マトリクス、許可・禁止一覧、analyzer観測値とraw cellの境界、loop分類限界、ライセンス・再配布境界、repository/local/manual/human test分類、後続WBS引き継ぎ。既存生成fixtureを優先し、外部UGEを標準CI必須依存にしない。
