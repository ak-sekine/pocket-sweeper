# 目的

旧方式の検証で成立した技術基盤を、新方式でも再利用できる部分と方式依存で再評価が必要な部分に分離して整理する。

# 作業内容

JSON、JSON→UGE、UGE→ASM、ASM→ROM、hUGEDriver、test ROM、artifact validation、seed/reproducibilityを実装・仕様・証跡から確認する。新しい作曲方式は決定しない。

# 入力

01519配下および01592配下の完了済み評価記録、関連仕様、既存実装。

# 成果物

再利用可能な技術契約と方式依存部分の整理文書。

# 完了条件

新方式に共通して再利用できる範囲と、作曲方式の選択後に再評価すべき範囲を根拠付きで記録する。

# 完了にしてはいけない条件

新方式の選択、実装、既存01519の履歴変更を行った場合は完了にしない。

# 確認結果

JSON Version 2、JSON→UGE、JSON→ASM、ASM→確認用ROM、hUGEDriver runtime、artifact validationを、方式変更後も契約を満たせば再利用できる技術基盤または条件付き基盤として整理した。composition generator、logical model、allocation、tempo/time resolution、loop生成、instrument/mapping、seed semantics、production rule、source/licenseは新方式選択後に再評価が必要な方式依存部分として分離した。新方式の選択・比較・実装は行っていない。

# 証跡

技術基盤整理文書: `docs/generated-song-technical-foundation.md`。参照した仕様・実装・既存評価証跡から、再利用条件と未確定事項を記録した。
