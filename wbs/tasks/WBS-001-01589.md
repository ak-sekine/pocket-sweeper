# 目的

01588で生成したhUGEDriver用ASMから、既存のVersion 1/Version 2対応sound test ROM builderを使って独立した確認用ROMを機械的に生成できることを確認する。
# 作業内容

既存`tools/build_sound_test_rom.py`を再利用し、Version 2では`hUGE_init_v2`、`none`では終了判定と更新停止を使用する。RGBDSでASM、driver、link、header fixを実行する。ROM生成後のSameBoy、実機、試聴、SFX検証は行わない。
# 入力

01588のJSON Version 2→ASM、hUGEDriver、既存RGBDS toolchain、sound test ROM contract。
# 成果物

01587 JSON→01588 ASM→`build_sound_test_rom.build_rom()` integration test、ROM生成契約文書。
# 完了条件

生成ASMからVersion 2確認ROMを生成し、RGBDS toolchainが成功する。Version 1回帰と既存builder testsを維持し、出力ROM・中間物の配置を確認する。
# 完了にしてはいけない条件

SameBoy、hUGETracker、実機、試聴、SFX共存、音楽品質を確認済みと扱わない。
# 確認結果

既存`build_sound_test_rom.py`を確認し、Version 2の`_loop_metadata`検出、`hUGE_init_v2`、`hUGE_bgm_finished`、RGBDSによるbuildが既に実装済みであることを確認した。01587のJSONを01588 converterへ渡し、そのASMを一時ファイルから既存builderへ渡すintegration testを追加した。RGBDSはrgbasm/rgblink/rgbfix `v1.0.1-157-gdecc5f71`で実行成功し、ROMは32KiBとして検証した。SFX、SameBoy、実機、seed再生成、1コマンド化は後続へ残した。
# 証跡

`docs/generated-song-test-rom.md`、`tests/test_bgm_generator.py`の01587→01588→ROM integration test。
