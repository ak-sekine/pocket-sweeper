# 目的

PD曲自動編曲prototypeをHumanが実際に試聴し、原曲認識、曲構造、4ch編曲、tempo、loop、Game Boy BGMとしての聴感を確認する。

# 作業内容

SameBoy等でROMを再生し、原曲として認識できるか、曲として成立しているか、melody、bass/accompaniment/rhythm、tempo、loop、Game Boy BGMとしての違和感を記録する。CodexはHuman結果を上書きしない。

# 入力

01693の同一run UGE/ROMとsource/provenance記録。

# 成果物

候補ごとのHuman試聴結果と未確認事項。

# 完了条件

Humanが実際に試聴し、観点ごとの結果と根拠を記録する。

# 完了にしてはいけない条件

Codexのmachine validationや推測だけで完了にしない。

# 確認結果

Humanが01693で生成されたMaple Leaf Rag prototype ROMをSameBoyで実際に試聴した。原文は「Maple Leaf Ragとは全く違う曲になっていました。」および「曲としても成立はしていませんが、自動作曲よりは進歩しているように感じます。」である。原曲認識、曲としての成立、過去方式との比較について結果を記録した。melody、bass/accompaniment/rhythm、tempo、loop、Game Boy BGMとしての聴感の個別評価はHumanから得ていないため未評価として記録した。原因の切り分けやproduction BGM採用判断は行っていない。

# 証跡

Human原文、試聴対象、評価観点、未評価項目、原因を確定しない注意事項を`docs/generated-pd-maple-leaf-rag-human-evaluation.md`に記録した。
