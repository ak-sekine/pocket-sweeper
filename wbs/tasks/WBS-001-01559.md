# 目的

Game Boy APUのCH1～CH4のハードウェア能力と物理的な編曲制約を調査し、機械検証可能な制約と作曲上・聴感上の未確定事項を分離する。
# 作業内容

CH1〜CH4、pulse/wave/noise、同時発音制限、duty、envelope、sweep、wave table、音域・音量・effectを、実際のハードウェア仕様から調査し、作曲ルールへ反映可能な制約と未確定事項を分ける。
# 入力

Game Boy APU仕様の出典と調査記録。
# 成果物

`docs/game-boy-apu-4ch-constraints.md` に、Game Boy CPU Manual、Pan Docs、GbdevWikiを根拠とした4ch仕様、レジスタ値域、周波数式、wave RAM、LFSR、Pocket Sweeperへの適用、未確定事項、後続WBSとの役割分担を記録した。
# 完了条件

CH1〜CH4、pulse/wave/noise、CH1/CH2差、duty、envelope、sweep、wave table/output level、CH4 LFSR/NR43、frequency、length、trigger、4ch共通制約について出典を付し、hardware-validとmusically-suitableを区別する。01560〜01565の担当範囲を混同せず、21曲UGE素材を品質根拠にしない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Game Boy CPU Manual、Pan Docs、GbdevWikiを確認した。現行の`docs/sound-spec.md`、`docs/json-format.md`、`src/hUGEDriver.asm`、`src/sound.asm`とのAPU仕様上の矛盾は確認されなかった。人による試聴、実機・エミュレータでの聴感確認は未実施であり、未確定事項として成果物に分離した。旧目的文は作業内容と不一致だったため、APU仕様調査の目的へ修正した。
# 証跡

`docs/game-boy-apu-4ch-constraints.md` の情報源、CH別仕様、機械検証表、適用・未確定事項。WBSの`outputs`および`related_files`から追跡可能。
