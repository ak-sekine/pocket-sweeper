# 目的

JSONから生成したUGEを既存`analyze_uge.py`で再解析し、生成入力から期待したorder/pattern/cell/loop/channel構造と一致することを自動検証する。
# 作業内容

生成UGEに対して既存analyze_uge.pyを実行し、4chのorder/pattern整合、64行、loop、raw cell/effect、未使用ch等が意図どおりであることを自動検証する。不足項目だけを追加し、既存解析機能を重複実装しない。
# 入力

自動生成UGE検証テスト、検証結果、追加した場合の不足機能。
# 成果物

生成入力と`read_file()`結果の一致を確認する自動検証テストと記録。
# 完了条件

生成入力から期待構造を定義し、既存解析結果との一致を自動テストで確認する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

2026-09-25、既存Version 2 fixtureをJSON→UGE→`read_file()`で再解析し、Song Version、4ch order/pattern、64-row、raw note/Instrument、C/E/B effect、used/unused channel、event_count、full/range/none loopの解析限界を自動検証した。analyzerとconverterに追加変更は行っていない。
