# 目的

01587のJSON Version 2楽曲データを、既存のJSON→hUGEDriver ASM converterで決定的に変換できることを保証する。
# 作業内容

既存`tools/json_to_huge_asm.py`を再利用し、01587の出力をJSON→ASMへ接続する。UGE経由、logical layerからの直接変換、ROM生成、RGBDS/link、Human verificationは実施しない。
# 入力

01587のJSON Version 2、既存JSON/ASM converter、hUGEDriver descriptor/loop contract。
# 成果物

01587 JSON→`json_to_huge_asm.build_asm()` integration test、既存JSON→UGEとのcross-check、変換契約文書。
# 完了条件

同一JSONから決定的なASMが生成され、JSON→UGEも成功する。pattern/order、64-row、instrument、note/rest/length、loop metadataは既存converterの検証に委譲する。
# 完了にしてはいけない条件

ROM生成、RGBDS assembly、SameBoy、hUGETracker、実機、試聴、SFX共存品質を確認済みと扱わない。
# 確認結果

01587が既存JSON Version 2を出力することを確認し、既存`json_to_huge_asm.build_asm()`を正式pipelineとして再利用した。UGE経由の変換や新しいASM generatorは追加せず、同一JSONをUGE/ASM双方へ渡すintegration testを追加した。Version 2 descriptorのloop metadata、既存hUGEDriver ABI、empty row、CH3 wave/CH4 noise変換は既存converterと既存テストを根拠に維持した。未解決のinstrument/wave/noise resolution、SFX、ROM、RGBDS、Human evaluationは後続へ残した。
# 証跡

`docs/generated-song-hugedriver-asm.md`、`tests/test_bgm_generator.py`の01587→01588 integration test。
