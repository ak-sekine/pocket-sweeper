# 目的

調査結果を確認し、prototypeで使用する入力形式とsource/provenance方針をHumanが選択する。

# 作業内容

MIDI、MusicXML、公開楽譜その他の候補を、特徴、入手性、権利、parser、Game Boy編曲、JSON接続の情報とともに確認して選択する。Codexは選択しない。

# 入力

01685の要件と01686の調査結果。

# 成果物

Humanによる入力形式・provenance方式の選択と根拠。

# 完了条件

Humanの判断が記録される。

# 完了にしてはいけない条件

Human判断なしにcompleteにしない。

# 確認結果

Humanは「いったんMusicXMLをベースに考えようと思います。」と判断した。これを、prototypeの入力形式はMusicXMLをベースとして後続WBSで具体化する、という範囲で記録する。MusicXMLを永久的・不可逆に採用したものではなく、具体的な技術的問題が確認された場合はMIDI等の別形式や別方式を再検討できる。parser/library、具体的MusicXML source、prototype曲、source保存方針、Human前処理、provenance schema詳細、4ch編曲rule、JSON Version 2変更・適合性は未決定である。

# 証跡

Human原文: 「いったんMusicXMLをベースに考えようと思います。」

01686の調査結果に基づき、MusicXMLがpart、measure、note、voice、staff、duration/divisions、time、key、direction/tempo、dynamics、repeat/ending等を扱うことは確認済みである。一方、Game Boy 4ch reduction、instrument mapping、polyphony reduction、quantization、runtime loop、JSON Version 2への最終適合性は後続WBSで確認する。MusicXMLの選択と、具体的sourceのlicense/provenance・利用許可は分離し、01690/01691へ引き継ぐ。
