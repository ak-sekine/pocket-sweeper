# 目的

01580のCompositionStructureを共通時間軸として、physical channelへ固定されない伴奏logical layerをseed再現可能に生成する。
# 作業内容

伴奏pattern definition/instance、realization、pitch relation、rest、duration、phrase/harmony reference、最小variationを実装する。harmony progressionは生成せず、caller-supplied harmony referenceだけを検証する。CH2、Instrument、UGE、bass、noise、SFX共存は扱わない。
# 入力

01579のGenerationContext、01580のCompositionStructure、01576のlogical layer model、一般音楽理論・伴奏/harmony調査、hardware/tool仕様。
# 成果物

`tools/bgm_generator.py`のlogical accompaniment model/generator、`tests/test_bgm_generator.py`の再現性・検証テスト、`docs/generated-accompaniment-layer.md`。
# 完了条件

同一context呼び出し順・同一structure・同一parameters/options・同一seedで同じ伴奏layerを生成し、pattern/phrase/event/harmony reference、範囲、duration、overlap、pitch/rest排他、unsupported realizationを機械検証できる。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Git履歴で、初回移行時の「CH2伴奏」は旧WBS文言の引き継ぎであり、現行01576の`logical layer != physical channel`と一致しないことを確認したため、タイトルを伴奏logical layerへ整理した。伴奏は01581のMelodyLayerを入力必須とせず、依存はGenerationContextを提供する01579とCompositionStructureを提供する01580に限定した。

Harmony progressionは実装せず、caller-supplied `harmony_ref`と利用可能参照集合だけを検証する設計にした。`sustained_tone`、`repeated_tone`、`rhythmic_support`、exact/relative offset variation、未割当physical channel、reference/範囲/overlap検証を実装した。Human evaluation、CH2 allocation、UGE mappingは実施・実装していない。
