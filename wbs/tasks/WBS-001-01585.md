# 目的

01580〜01584のlogical layerをphysical allocation候補へ接続し、Game Boy 4ch、hUGEDriver、Pocket Sweeper SFX共存に関する機械検証可能な制約を定義・実装する。
# 作業内容

logical layerとphysical channelを分離したallocation model、CH1〜CH4 capability、exclusive allocation、required/temporarily_degradable/optional policy、SFX occupancyを実装する。`src/sound.asm`とhUGEDriverのcurrent factを根拠に、CH1/CH4 conflict、CH2 future occupancy、timeline継続、unmute復帰をmachine-checkableに記録する。logical→UGE/ASM/ROM変換や聴感保証は実装しない。
# 入力

01579〜01584の生成layer、01576のallocation model、Game Boy hardware rules、`src/sound.asm`、`src/hUGEDriver.asm`、sound/JSON仕様、既存SameBoy確認記録。
# 成果物

`tools/bgm_generator.py`のallocation/SFX validation、`tests/test_bgm_generator.py`のmachine validationテスト、`docs/game-boy-bgm-allocation-sfx-constraints.md`。
# 完了条件

4 channel capability、exclusive allocation、SFX occupancy、degradation、timeline継続、required layer preemptionを機械検証でき、CH1 conflict等の未確定事項とHuman-only条件を文書化する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01579〜01584が`complete`であることを確認した。入力logical layerをphysical channelへ固定変換せず、caller-supplied allocationを検証する設計とした。`src/sound.asm`ではPulse1 SFX=CH1、Noise/Cursor SFX=CH4、SFX中も`hUGE_dosound`とBGM位置進行、終了時unmuteを確認した。hUGEDriverではmute channelを更新しない実装を確認した。

CH1 melody policyとPulse1 SFXの競合は解消せず、required allocationをmachine violation、degradable allocationをHuman reviewとした。CH4 Noise SFXはdegradable/optional時のみmachine-valid、CH2 SFXは未実装扱い、CH3はcurrent non-occupancyとしてのみ記録した。既存SameBoy確認はCH2/CH4 mute範囲に限定して参照し、CH1欠損の聴感を確認済みとはしていない。3ch/4ch方針も決定していない。
