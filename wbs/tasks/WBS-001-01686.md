# 目的

PD曲を扱う入力形式とsource/provenance管理方式を調査する。

# 作業内容

MIDI、MusicXML、machine-readable公開楽譜、その他symbolic representationについて、polyphony、measure/time signature/key、tempo、dynamics、part、repeat、parser/library、JSON接続、license metadata、determinismを調査する。原曲、edition、採譜、MIDI化、MusicXML化、録音、編曲の権利を混同しない。採用決定はしない。

# 入力

01685の要件、公式仕様、公式license、公開repository。

# 成果物

入力形式・provenance方式の調査文書と出典。

# 完了条件

候補形式の事実、接続可能性、権利論点、未確認事項が記録される。

# 完了にしてはいけない条件

Human選択なしに入力形式を採用決定した場合は完了にしない。

# 確認結果

MIDI、MusicXML、公開されるmachine-readable楽譜source、その他symbolic representationを、note/timing、score structure、parser/library、JSON Version 2接続、provenance/license、再現性の観点で調査した。MIDI/MusicXMLの採用、parserの導入、具体的な曲/sourceの選定は行っていない。composition、edition、arrangement、transcription、symbolic encoding、recordingを分離し、作曲自体がPDでも具体的source fileの利用可否は個別確認が必要であることを記録した。01687でHumanが入力形式を選択し、01690で具体的sourceの権利・provenanceを確認できる状態にした。

# 証跡

`docs/generated-pd-input-format-provenance-investigation.md` に、公式資料のURL、資料名、提供元、確認事実、調査日、候補比較表、JSON Version 2接続、provenance metadata候補、再現性、未確定事項、01687/01690へのhandoffを記録した。
