# 目的
採用済みMIDIの87音をCH1 / Pulse1だけで再生する16秒ループROMへ変換し、MIDIとUGEの全イベントをmachine照合する。
# 作業内容
入力SHA-256、pitch/onset/end/rest、60Hz row量子化、tempo差、loop境界、order境界の発音継続を検証する。JSON Version 2では継続用の空行`hold`を導入する。
# 入力
ユーザー提供`maple_leaf_rag_16bars_melody_bridge.mid`、SHA-256 `b009472e114c5527125c5a56cb58a01683cb7cd8d38b903ea0673a02044820a0`。
# 成果物
楽曲定義JSON、UGE、hUGEDriver ASM、sound-test ROM、全87音の照合・timing・loopレポート。
# 完了条件
JSON→UGE→ASM→ROM build成功。UGEで音程・発音順・量子化row・休符・loopを照合し、SameBoy用ROMを配布できる。
# 完了にしてはいけない条件
SameBoyでの聴感・音楽品質・Humanによる音楽内容確認をCodexのmachine検証で代替しない。
# 確認結果
入力SHA、format 1 / PPQ 384 / 120 BPM / 2/4 / 87音を確認。発音pitch・順序・開始row・終了rowは87/87一致。休符10か所、CH1以外の発音0。tempo=1、15 ordersのfull cycleで960 rowsを構成する。GB VBlank推算は約16.073秒、119.455 BPM。詳細と全音表はconversion reportを参照。Human試聴は01771で待機する。
