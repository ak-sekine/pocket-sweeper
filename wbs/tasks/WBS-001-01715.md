# 入力

01711〜01714のdiagnostic reports。

# 成果物

Humanの改善対象選択と次工程。

# 完了条件

# 確認結果

Human原文: 「長さ、テンポ、リズム、音程・メロディは個別ではなく、まとめて扱ってください。」

対象範囲は、01711〜01714で確認した個別差分を個別parameter tuningとして扱わず、原曲の時間軸・音符・メロディ構造をできるだけ保持したままGame Boy向けへ縮約する処理全体とする。01713/01714で確認したcross-measure local-row aggregation、2566→16縮約、melody 8 eventsの分散選択を含める。

具体的な修正方式、collision key、4ch割当、tempo/TicksPerRow、JSON V2変更、production採用は未決定。次工程で設計・実装・machine再検証・ROM生成を行い、最後にHumanが試聴・実用性評価を行う。

# 証跡
