# 目的

01591の一括pipelineを事前に固定した複数seedへ適用し、01594の人手試聴へ渡せる構造検証済み候補ROMを準備する。
# 作業内容

既存fixtureのseed variationを実測したうえで、別の評価専用candidate profileを追加した。seed 1、5、7をcandidate-01〜03として生成し、JSON→UGE→01569 analyzer→ASM→RGBDS ROM、manifest/hashを保存した。音楽品質や採用可否は判断しない。
# 入力

01591 CLI、既存generator/converter、candidate profile、事前固定seed集合、01569 UGE analyzer。
# 成果物

3候補のJSON、UGE、ASM、ROM、manifestとcandidate index文書。生成物はbuild配下で再生成可能なためcommitしない。
# 完了条件

複数のunique candidate ROM、seed対応、各UGEの機械検証、RGBDS生成、duplicate確認、01594用ROM path、代表候補のhash再生成一致を記録する。
# 完了にしてはいけない条件

SameBoy、試聴、長時間loop、SFX共存、音楽品質、Pocket Sweeper適合性を確認済みと扱わない。
# 確認結果

既存fixtureをseed 1〜3で実測しJSON/UGE/ROMが同一だったため候補には使用しなかった。既存motif candidate選択を用いる評価専用profileでseed 1/5/7を生成し、3候補のJSON/UGE/ASM/ROMがすべてuniqueで、Song Version 6・order alignment一致、RGBDS build成功を確認した。candidate-01を再生成して全artifact hash一致を確認した。candidate ID・seed・ROM pathを01594向け文書へ記録した。
# 証跡

`docs/generated-song-candidates.md`、`tools/generation_profile_candidates.py`、`build/generated-candidates/candidate_01`〜`03`（再生成可能・未commit）。
