# 目的

01579〜01585のlogical compositionをMIDIなしで、明示的なphysical allocationとresolution contextに基づき既存JSON Version 2のGame Boy向け楽曲データへ決定的に変換する。
# 作業内容

CompositionStructureとlogical layerを入力に、01585のallocation/SFX machine validationを通過したものだけを既存JSON Version 2へ変換する。pitch、instrument、Noise mapping、tick-to-rowはcaller-suppliedとし、不足時はsilent fallbackせず拒否する。ASM、UGE、ROM生成は01588以降へ残す。
# 入力

01578の生成モデル、logical layer、明示的LayerAllocation、pitch/instrument/noise resolution、既存JSON Version 2のtiming/loop契約。
# 成果物

`docs/generated-song-game-boy-conversion.md`、`tools/bgm_generator.py`のJSON Version 2変換adapter、専用の変換テスト。
# 完了条件

`convert_to_json_v2`、変換契約文書、決定性・割当・解決不足・既存converter互換性のテスト。
# 完了にしてはいけない条件

人の試聴、SameBoy、ROM、hUGEDriver実行確認を完了したと扱わない。変換のmachine correctnessのみで完了とする。
# 確認結果

Git履歴で、初期移行commit `4a90eea` の01587に依存先がなく、後続の正規化commit `699b460` で親group `01586` が追加されたことを確認した。01586は01587を子孫に含むため、この依存はgroup aggregationと循環し実行デッドロックになる。01587は実際に入力として使用する完了済み生成基盤01578だけへ依存する形へ修正した。既存JSON Version 2と`tools/json_to_uge.py`を出力境界として再利用し、MIDI・JSON Version 3・ASM/ROM生成は追加していない。CH1 Pulse1 SFX競合、3ch/4ch方針、pitch/harmony/instrument/noise resolution不足は未解決のまま明示した。
# 証跡

`docs/generated-song-game-boy-conversion.md`、`tools/bgm_generator.py`の`GameBoyConversionInput`/`convert_to_json_v2`、`tests/test_bgm_generator.py`の変換契約テスト。
