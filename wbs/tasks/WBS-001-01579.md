# 目的

後続のルールベースBGM生成処理から共通利用できる、明示seedに基づく再現可能なPython乱数生成基盤を実装する。
# 作業内容

明示的な整数seedを受け取る独立PRNG付きGenerationContextと、後続WBSが利用できる最小のchoice・range・weighted choice・shuffle APIを実装する。global random状態から分離し、生成versionとseedを結果metadataへ保持する。曲生成や音楽的weightは実装しない。
# 入力

01571で定義したルール・layer設計、`docs/sound-spec.md`、`docs/json-format.md`、既存Pythonツール・テストの規約。
# 成果物

`tools/bgm_generator.py`、`tests/test_bgm_generator.py`、`docs/seeded-generation-foundation.md`。
# 完了条件

同一version・同一入力・同一seedのprobeがcontext間およびプロセス間で再現し、global random状態に影響されないことを自動テストで確認する。seed型、candidate順序、weighted choiceのエラー、metadataを文書化する。
