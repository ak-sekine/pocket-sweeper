# 目的

diagnostic結果を確認したHumanが、次の改善・追加調査方針を選択する。

# 作業内容

原因候補、比較結果、残る不確実性を提示し、実装変更・別conversion path・別source・追加試聴等の方針をHumanが判断する。

# 入力

01697〜01702のdiagnostic設計・検証・整理結果。

# 成果物

Human選択結果と選択理由。

# 完了条件

Humanの明示判断を原文・対象範囲・次工程として記録する。

# 完了にしてはいけない条件

CodexがHumanの代わりに改善方針やproduction採用を決定する。

# 確認結果

Humanは次の判断を明示した。

> まず、MIDI→MusicXMLで発生している音符のタイミングのズレを調べる。

次に調査する対象として、source MIDIからgenerated MusicXMLへの音符開始時刻（onset）差分を選択した。01698で確認された差分の発生箇所・理由を、次工程で調査する方針である。

この判断は原因の確定、実装変更、production採用の判断ではない。原因調査は本WBSでは実施していない。

# 証跡

Human判断の原文、選択した対象範囲、未選択事項を [Human判断記録](../../docs/generated-pd-maple-leaf-rag-human-direction.md) に記録した。次工程は WBS-001-01704 として登録した。
