# 目的

CH4 noise hardwareとゲームBGMのrhythm / density設計を接続し、長時間loop、注意、SFX共存を含む生成・検証条件として整理する。CH4専用drum patternは固定しない。
# 作業内容

Noise channelの実仕様と、ゲームBGMで長時間再生・注意喚起・反復疲労を考慮したリズム設計を、追跡可能な資料に基づき整理する。
# 入力

出典付きの調査記録と設計上の未確定事項。
# 成果物

`docs/game-boy-ch4-noise-rhythm-density-research.md` に、情報源、CH4 hardware、noise texture、rhythm layer、density、repetition / variation、fill、attention、long-loop fatigue、pulse/bassとの関係、CH4欠落/SFX、分類、自動生成候補、既存仕様、未確定事項、01565への引き継ぎを記録した。
# 完了条件

信頼できる複数資料を確認し、CH4 hardware、noise textureとpercussion-like role、rhythm layer、density、反復・変奏、fill、attention、long-loop fatigue、pulse/bassとの関係、現行SFXによるCH4欠落を整理する。Hardware-valid / Rhythmic relationship / Musically-suitable、Hard constraint / Soft rule / Parameter / Human evaluationを分離し、drum役割・pattern・density・fill頻度・具体値を根拠なく固定しない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Pan Docs、Open Music Theory、Texas A&M University–Corpus Christi、Berndtらのゲーム音楽サーベイ、Audiokinetic公式資料および既存仕様・実装を確認した。LFSR、7/15-bit、clock、envelope、length、trigger、DAC、noise texture、rhythm/density、反復・変奏、attention、CH4欠落とSFX共存を整理した。現行`sound-spec.md`のCH4 mute耐性方針は既存仕様として分離し、今回の採用候補と混同していない。kick/snare/hi-hat固定、pattern・density・fill頻度・parameter defaultは未確定である。試聴・実機・エミュレータ確認は未実施である。01565のhUGETracker/hUGEDriver詳細は引き継いだ。21曲UGE素材は品質根拠に使用していない。旧目的文は現在の役割に合わせて修正した。
