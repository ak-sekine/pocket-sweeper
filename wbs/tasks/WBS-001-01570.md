# 目的

解析ツールが出力した解析結果を、人が少数の既存曲で妥当性確認する。Codexによる構造・数値の自動検証とは分離し、人の確認なしに完了扱いにしない。
# 作業内容

01569の出力から確認対象曲を選び、曲・pattern・channel・note・length・Instrument・effect等の対応を人が確認する。確認方法、対象、結果、未確認事項を記録する。
# 入力

01569の解析結果、確認対象のUGEまたはASM、必要に応じた人による確認記録。
# 成果物

人による解析結果確認記録。
# 完了条件

人が確認対象を実際に確認し、解析結果との一致・不一致と未確認事項を記録する。
# 完了にしてはいけない条件

人による確認記録がない場合、Codexの自動検証結果だけで完了にしない。
# 確認結果

2026-09-25、ユーザー本人がhUGETracker GUIで以下の既存UGE 2曲を確認し、結果をHuman verificationとして記録した。Codex自身によるGUI確認ではない。

- `01-Title-Prelude.uge`（`Prelude in C major`）: 解析結果はSong Version 6、tempo 12、pattern_count 16、order_counts `[4, 4, 4, 4]`、order_alignment `一致`、loop `implicit_full_order_cycle`、CH1/CH2 used、CH3/CH4 unused。GUIでCH1の最初のpatternのrow 00〜63にnoteがあること、代表cellがrow 00 `C-5 01`（`note=24, inst=1`）、row 01 `E-5 01`（`note=28, inst=1`）、row 02 `G-5 01`（`note=31, inst=1`）と一致することを確認した。GUI effect欄は空で、解析結果の`effect=0, param=00`と一致した。CH2は最初の2 patternが空で後半2 patternにnoteがあり、CH3/CH4は全patternが空で、channel使用有無も一致した。
- `free_01_hypergolic_blast_off.uge`（`Hypergolic Blast Off GB`）: 解析結果はSong Version 6、tempo 8、pattern_count 52、order_counts `[19, 19, 19, 19]`、order_alignment `一致`、loop `complex_position_jumps`、CH1〜CH4 used。GUIのorder表示が1始まりであることを踏まえ、Noise（CH4）のOrder 16 / row 63およびOrder 19 / row 32に`B01`があることを確認した。これは解析結果の0始まりsource order 15/18、raw target 1、解釈target order 0と対応し、異なるsource orderに基づく`complex_position_jumps`分類とも整合した。Duty1/Duty2/Wave/Noiseの4chすべてにイベントがあり、CH1〜CH4 usedとも一致した。

確認範囲では、channel使用有無、pattern/order対応、代表note、Instrument番号、effectなし、B effect、position jump、loop分類がGUI表示と`analyze_uge.py`解析結果で一致した。全cellを網羅確認したものではない。

01570は少数の既存曲で解析結果を人が確認するWBSであり、未確認事項があることだけを理由に未完了とはしない。
