# 目的

解析ツールが出力した解析結果を、人が少数の既存曲で妥当性確認する。Codexによる構造・数値の自動検証とは分離し、人の確認なしに完了扱いにしない。
# 作業内容

01569の出力から確認対象曲を選び、曲・pattern・channel・note・length・Instrument・effect等の対応を人が確認する。確認方法、対象、結果、未確認事項を記録する。
# 入力

01569の解析結果、確認対象のUGEまたはASM、必要に応じた人による確認記録。
# 成果物

人による解析結果確認記録。
# 完了条件

人が確認対象を実際に確認し、解析結果との一致・不一致と未確認事項を記録する。
# 完了にしてはいけない条件

人による確認記録がない場合、Codexの自動検証結果だけで完了にしない。
# 確認結果

未実施。01569の解析結果が整備された後、人による確認を実施する。
# 証跡

人による確認記録、対象曲・対象項目・確認結果。
