# 目的
生成した16秒単旋律ROMの聴感とループ接続をSameBoyでHumanが確認する。
# 作業内容
SameBoyで現行ROMとbridge +12半音比較ROMを再生する。旋律、6.25〜7.375秒の橋渡し9音、8〜9秒と12〜13秒の同音連打、約16秒ループ、休符、音切れ・余分な再発音を確認する。
# 入力
現行の`build/maple_leaf_rag_16bars_melody_loop.gb`と候補の`build/maple_leaf_rag_16bars_melody_bridge_octave_up.gb`。GitHub Actions run `41586140138`のartifact ID `13207473800` / `maple-leaf-rag-bridge-comparison-roms`からiPhoneへ取得できる。
# 成果物
HumanのSameBoy試聴結果とROM SHA-256。
# 完了条件
両ROMのhashとHumanの評価、bridgeの自然さ、同音連打、tempo、旋律・休符・loop境界の確認結果を記録する。両案が不適切な場合は希望する修正方向と追加調査を明記する。
# 完了にしてはいけない条件
CodexがHumanの聴感や音楽品質判断を代行しない。
# 確認結果
Humanは現行ROM SHA-256 `82773f4ac58a4f676110feb72eeb29e0208c0795a4c46ca213be1ce2f14bfd3f`をSameBoyで試聴済み。8〜9秒G#6反復、12〜13秒G#5反復、クリック/不自然な音切れ、約16秒loop/tempoはOK、6〜7秒bridgeはNG。2026-11-03にHumanが採用済み87音MIDIは違和感なし、現行ROMの6〜7秒bridgeは違和感あり、bridge +12半音候補ROMは現行より違和感が大きいと評価した。+12半音候補は不採用とし、現行の楽曲データを維持する。原因は未特定でbridgeの問題は未解決のため、本WBSはincompleteを維持する。比較結果とROM hashは`docs/generated-maple-leaf-rag-16bars-melody-human-evaluation.md`を参照。
