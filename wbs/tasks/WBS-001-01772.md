# 作業内容
event 30〜38の音程、row、note cut、order/hold、Instrument、Pulse1周波数を比較する。入力MIDIが手元にない場合は変換レポートの記録値を使い、元trackや編曲意図を補完しない。原因が確定しない音楽的判断はHumanに残す。
# 入力
Humanの試聴結果、WBS-001-01770のJSON/UGE/ASM/ROMとconversion report。提供MIDI SHA-256は`b009472e114c5527125c5a56cb58a01683cb7cd8d38b903ea0673a02044820a0`だが、今回のworkspace/repositoryにはMIDI fileがない。
# 成果物
diagnosis report、event 30〜38のみを+12半音した比較JSON/UGE/ASM/ROM、既存版と比較ROMを含むGitHub Actions artifact。
# 完了条件
JSON/UGE/ASMが同じ9音・rowを表し、他音・休符・CH1-only・11同音E00・960-row loopが維持される。テストとRGBDS buildが成功し、原因の確定・未確定を分けて記録する。
# 完了にしてはいけない条件
HumanのSameBoy合否を代行しない。WBS-001-01771の比較ROM試聴までbridgeの問題を解決済みとしない。
