# 目的

評価候補について、UGEと確認用GB ROMを同一runで比較できる技術確認を整える。

# 作業内容

同一runのUGE/ASM/ROMを追跡し、tempo、row、pattern/order、loop、runtime更新のmachine evidenceを確認する。必要な代表候補はHumanが比較できる形で明示する。作曲品質は判定しない。

# 入力

01675の候補artifact、既存tempo契約、前回のruntime mismatch分析。

# 成果物

同一run対応表、machine validation記録、Human再確認用artifact一覧。

# 完了条件

比較対象runが一致し、技術的不一致の有無と未確認範囲が記録される。

# 完了にしてはいけない条件

異なるrunのartifactを比較したり、Codexだけで聴感一致を完了扱いにした場合は完了にしない。

# 確認結果

既存candidate-01 fixed runのHuman一致確認は記録済み。新profile候補は未確認。

# 証跡

UGE/ROM path、hash、時間契約、Human確認依頼。
