# 目的

評価候補について、UGEと確認用GB ROMを同一runで比較できる技術確認を整える。

# 作業内容

同一runのUGE/ASM/ROMを追跡し、tempo、row、pattern/order、loop、runtime更新のmachine evidenceを確認する。必要な代表候補はHumanが比較できる形で明示する。作曲品質は判定しない。

# 入力

01675の候補artifact、既存tempo契約、前回のruntime mismatch分析。

# 成果物

同一run対応表、machine validation記録、Human再確認用artifact一覧。

# 完了条件

比較対象runが一致し、技術的不一致の有無と未確認範囲が記録される。

# 完了にしてはいけない条件

異なるrunのartifactを比較したり、Codexだけで聴感一致を完了扱いにした場合は完了にしない。

# 確認結果

01675のquality_candidate_01〜03について、manifest/current artifact SHA-256、JSON/UGE/ASM/ROM同一run、Version 2、tempo=1、full loop、4 channel、order alignment、UGE構造、ASM descriptor tempo、hUGE_init_v2・hUGE_dosound・VBlank更新契約を機械確認した。Humanは品質評価候補のUGEとGB ROMを再生比較し、「ugeとgbを再生した感じは同じに聞こえました。」と報告した。Human evidenceは聴感上の全体的一致に限定し、厳密な時間測定・channel別比較・音楽品質・SFX共存・Pocket Sweeper適合性へ拡張しない。完了条件を満たしたためcompleteとする。

# 証跡

同一runのUGE/ROM path、hash、JSON/UGE/ASM tempo、pattern/order/loop、runtime契約、Human確認結果: `docs/generated-song-quality-runtime-validation.md`。Human報告は「ugeとgbを再生した感じは同じに聞こえました。」であり、精密測定結果ではない。
