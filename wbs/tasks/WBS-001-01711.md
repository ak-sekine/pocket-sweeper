# 目的

source全体とprototypeが実際に扱う範囲の長さを比較する。

# 作業内容

MIDI全体、NormalizedScore、ArrangementPlan、JSON 64-row window、UGE order/pattern、ROMの終了・loopを数値で比較する。

# 入力

01708の修正版artifactとsource hash。

# 成果物

length diagnostic reportとevent/range mapping。

# 完了条件

各stageの範囲・長さ・loop/terminationをmachine evidenceで記録する。

# 完了にしてはいけない条件

長さの差だけでHuman音楽評価の原因や改善方法を確定しない。

# 確認結果

修正版artifactをsource hash検証付きで測定した。source/NormalizedScoreは全2566 events、ArrangementPlanは16 selected、JSON/UGE/ROM dataは64-row patternであることを確認した。16 selected eventsはsource measure 23〜144に散在し、最後のsource endまで到達している。64-row boundaryによる追加除外は0件だった。

# 証跡

実行command、stage別数値、artifact hashを [length diagnostic report](../../docs/generated-pd-maple-leaf-rag-length-diagnostic.md) とmachine-readable diagnosticに記録した。
