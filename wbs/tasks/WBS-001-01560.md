# 目的

一般音楽理論に基づき、ルールベース自動作曲で利用候補となるscale/key、melody、harmony、rhythm、cadence等を調査し、一般理論・作曲上の手法・ジャンル慣習・Pocket Sweeper固有の選択を分離する。
# 作業内容

scale/key、音程、melody、motif、phrase、反復・変奏、harmony、chord progression、rhythm、cadence、bass、accompanimentを調査する。ポピュラー音楽の慣習を無条件にGame Boyルールへ変換しない。
# 入力

出典付きの調査記録と、採用可否・適用条件。
# 成果物

`docs/general-music-theory-for-rule-based-generation.md` に、信頼できる複数資料の出典、一般理論、自動生成へのhard constraint/soft rule/parameter/human evaluation候補、Pocket Sweeperへの直接適用候補・未確定事項、後続WBSへの引き継ぎを記録した。
# 完了条件

scale/key、interval、melody、motif/phrase、repetition/variation、harmony/chord/progression、rhythm/meter/beat、note duration/rest、cadence、bass/accompanimentについて、主要主張ごとに出典と適用条件を記録する。一般理論とジャンル慣習を分離し、自動生成への利用候補を分類する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Open Music Theory、Benward/Sakerの教科書、Open Textbooksの入門教材、College Board AP Music Theory、Berkleeの教育資料を確認した。一般理論調査の完了条件を満たし、具体的なkey、tempo、meter、phrase長、chord progression、channel割当等は未確定として残した。人による試聴は実施しておらず、聴感品質を確認済みとはしていない。旧目的文は現タイトル・作業内容に合わせて修正した。
