# 目的

解析元コーパスを統計学習用コーパスではなく、既存Game Boy楽曲の設計パターン抽出元として扱う方針を決める。
# 作業内容

A判定21曲を現時点の解析元とする。ただし21曲を統計学習に十分なデータセットとは扱わず、構造、channel、motif、伴奏、bass、noise等の設計パターンを抽出するための実例として扱う。解析元コーパスとPocket Sweeper採用曲（現時点0曲）は分離する。
# 入力

WBS-001-01549、docs/sound-spec.md、docs/game-boy-music-source-candidates.md。
# 成果物

解析元コーパスの用途方針と、採用曲との分離方針。
# 完了条件

解析元を統計学習用ではなく設計パターン抽出元として扱い、A判定21曲と採用曲0曲を分離する方針を記録する。
# 完了にしてはいけない条件

01549の確定結果と矛盾する場合は完了にしない。
# 確認結果
