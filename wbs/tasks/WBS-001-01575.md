# 目的

自動作曲ルールごとに、根拠・出典・適用条件・確定状態・許可用途・禁止推論・検証状態・未確定事項を追跡できる共通形式を定義する。
# 作業内容

一般理論、ゲームBGM技法、Game Boy、hUGETracker/hUGEDriver、Pocket Sweeper仕様、人の試聴評価、形式テストを区別して、出典、適用条件、確度、未確定事項を記録できる形式を定義する。
# 入力

根拠記録テンプレートまたはデータ形式。
# 成果物

`docs/composition-rule-evidence-schema.md` に、source/evidence、rule kind、status、applicability、allowed use、prohibited inference、source reference、conflict、human evaluation、machine validation、implementation status、rule dependency、supersessionのschemaと記入例を記録する。
# 完了条件

21曲の統計・多数派を品質根拠として記録できない運用を含め、追跡可能な形式を定義する。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

01572・01573・01574が`complete`であることを確認した。Hardware/Tool、Theory、Corpus observation、Pocket Sweeper policy、Human evaluationを区別し、capabilityとhard constraint、machine-checkableと実装済み、statusとconfidenceを分離した。corpus observationから作曲品質、default parameter、preferred channel role等を推論しない禁止事項をschemaと例へ組み込んだ。実際のGUI・試聴・実機確認は行っていない。
# 証跡

`docs/composition-rule-evidence-schema.md` のsource/evidence分類、必須フィールド、structured template、記入例A〜G、21曲UGEの禁止推論、review checklist、01576/01577への引き継ぎ。
