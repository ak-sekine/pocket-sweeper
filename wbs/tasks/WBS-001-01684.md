# 概要

パブリックドメイン曲を入力としてGame Boy向けBGMへ自動編曲する方式を、要件整理、入力・権利確認、4ch編曲設計、prototype、end-to-end生成、Human試聴、実用性評価まで段階的に検証する。Humanが選択した方式を具体化するgroupであり、production版BGM完成や新方式の先行決定は目的としない。

# 配下の作業

- WBS-001-01685 PD曲自動編曲方式の要件と処理境界を整理する
- WBS-001-01686 PD曲の入力形式とsource/provenance方式を調査する
- WBS-001-01687 入力形式をHumanが選択する
- WBS-001-01688 Game Boy 4ch自動編曲ルールを設計する
- WBS-001-01689 JSON Version 2との適合性を確認する
- WBS-001-01690 自動編曲prototype用PD曲の権利・provenanceを調査する
- WBS-001-01691 prototype用PD曲をHumanが選択する
- WBS-001-01692 自動編曲prototypeを実装する
- WBS-001-01693 prototype曲をend-to-endで生成する
- WBS-001-01694 HumanがSameBoyで試聴評価する
- WBS-001-01695 自動編曲方式の実用性を評価する
- WBS-001-01696 Maple Leaf Rag自動編曲prototypeの原曲性喪失原因を切り分ける

# 確認結果

01685〜01695が完了した時点ではgroup aggregation ruleを満たして一度completeとなった。その後、原曲性喪失原因を切り分ける01696を追加したためincompleteへ戻った。現在は01696配下の01697〜01704も完了し、全子孫がcompleteとなったためgroup aggregation ruleに従いcompleteとする。これはproduction版BGM完成や新方式の先行決定を意味しない。
