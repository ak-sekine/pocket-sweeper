# 目的

prototype候補曲と具体的sourceの権利・provenanceを、Human選択前に調査可能な状態へ整理する。

# 作業内容

composer/traditional、publication/date、composition自体のPD根拠、具体的source file、source license、edition/arrangement/transcription、repository保存、商用ROM利用、GitHub公開を確認する。未確認事項を推測で閉じない。

# 入力

01687の入力形式選択、公式権利資料、候補source。

# 成果物

候補曲・source・license・provenance調査文書。

# 完了条件

Humanが曲を選ぶための権利・provenance事実と未確認事項が整理される。

# 完了にしてはいけない条件

確認できない権利を「問題なし」と判断した場合は完了にしない。

# 確認結果

OpenScore Liederの4個の具体的候補について、composition、edition、arrangement、transcription、symbolic encoding、recordingを分離して調査した。README/LICENSEと個別`.mscx` metadataで、スコアデータのCC0 1.0、score path/ID、作曲者、作品番号、転記情報、MusicXML `.mxl`への公式変換経路を確認した。日本の文化庁の死後70年原則も確認し、compositionは通常のlife+70分析でPDと整理した。

sourceの商用ROM利用、GitHubへのMusicXML公開、派生JSON/UGE/ASM/ROMは、CC0対象のscore dataに限り「conditionally allowed」と記録し、歌詞・翻訳・特定edition・recording・最終法的判断を未確認のまま残した。sourceをdownloadせず、hashや選択済みcommitは取得していない。Humanの候補選択は行っていない。

Humanの希望により、追加候補としてScott JoplinのMaple Leaf Ragを調査した。Mutopiaのpiece pageと配布directoryで、LilyPond、MIDI、PDF、Public Domain表示、1899 edition reproduction、typesetter/maintainer情報を確認した。Mutopia公式配布物にdirect MusicXMLはなく、LilyPond→MusicXMLは公式toolchainで安定経路を確認できなかった。MIDI→MusicXMLはMuseScore Studioの公式import/exportで技術的に可能だが、固定version/settings・変換実行・MusicXML hashは未取得とした。Mutopia contributionの利用範囲はcommercial ROMを含めconditionally allowed、converted MusicXMLと派生artifactは具体的生成物確認前はunclear/conditionally allowedと記録した。01691のHuman選択は行っていない。

# 証跡

`docs/generated-pd-prototype-rights-provenance-investigation.md` に、候補比較、具体的source path/format、CC0、compositionのjurisdiction別整理、GitHub/商用ROM/派生artifactの条件、provenance、一次資料URL、未確認事項を記録した。
