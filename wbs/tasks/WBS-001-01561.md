# 目的

ゲームBGMの可変滞在時間・長時間loopを前提に、motifのidentityを保ちながら反復疲労を抑えるrepetition・variationと、layer追加・削減の設計候補を、信頼できる資料から整理する。
# 作業内容

ゲームBGM特有の反復・変奏、layer削減時にも成立する編曲、注意を過度に奪わない展開を、出典を追跡できる形で調査する。21曲の多数派から品質ルールを導かない。
# 入力

出典付きの調査記録。
# 成果物

`docs/game-bgm-motif-variation-layer-research.md` に、情報源、motif identity、repetition、variation、layer、attention、layer削減時のgraceful degradation、自動生成分類、Pocket Sweeperへの適用、未確定事項、後続WBSへの引き継ぎを記録した。
# 完了条件

複数のゲーム音楽・interactive audio資料を確認し、motif identity、exact/modified repetition、variation、layer、attention、layer削減時の成立性を整理する。Hard constraint / Soft rule / Parameter / Human evaluation候補を分離し、具体的な回数・確率・channel役割を根拠なく固定しない。adaptive musicの高度な技法を必須仕様にせず、21曲UGE素材を品質根拠にしない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

資料5件を確認した。ゲーム音楽の反復変奏とlayer構造の一般的な設計候補を記録し、資料から確定できないmotif保持属性、variation量、layer欠落時の聴感品質、注意を奪わない具体値は未確定として分離した。人による試聴は未実施であり、Human evaluation候補として記録した。CH1〜CH4の具体的役割は確定せず、01562〜01565へ引き継いだ。21曲UGE素材は品質根拠に使用していない。旧目的文は現タイトル・作業内容と一致する目的へ修正した。
