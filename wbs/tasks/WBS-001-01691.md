# 目的

権利・provenance調査を確認し、prototypeで使用するPD曲と具体的sourceをHumanが選択する。

# 作業内容

候補曲、source file、license、保存・公開範囲、商用ROM利用可否の確認結果を踏まえ、Humanが曲を選択する。Codexは曲を決定しない。

# 入力

01690の権利・provenance調査結果。

# 成果物

Humanが選択したprototype曲、source、利用範囲、判断根拠。

# 完了条件

Humanの曲選択と権利上の未確認事項が記録される。

# 完了にしてはいけない条件

Human判断なし、または未確認権利を黙って許可扱いにした場合は完了にしない。

# 確認結果

Humanはprototype曲として `Maple Leaf Rag` を選択した。

- Composer: Scott Joplin
- Source project: Mutopia Project
- Source identity: `Maple Leaf Rag (Mutopia-2011/11/13-23)`
- 参照source: `maple.ly`、`maple.mid`、`maple-a4.pdf`
- prototype入力経路: `Mutopia MIDI → MusicXML → normalized representation → ArrangementPlan → JSON Version 2 → UGE → ASM → ROM`

HumanはprototypeでMutopia MIDIからMusicXMLへ変換する経路を許容し、prototype生成としてJSON/UGE/ASM/ROMの生成を許容した。変換済みMusicXMLのlicense/provenanceが完全確認済みとは扱わず、source URL/version/hash/conversion procedureを保持する方針とした。01690で確認されたsource license、commercial use、GitHub公開、派生artifactの区分（`confirmed`、`conditionally allowed`、`unclear / not confirmed`）と未確認事項を引き継ぐ。

prototypeでHumanが十分な品質と評価した場合、Game Boy arrangementをPocket Sweeperのプレイ中BGM候補として使用することを想定する。ただしproduction BGMとしては未採用であり、後続prototype生成、Human試聴、実用性評価後に判断する。

Mutopia `.ly`/`.mid`およびgenerated MusicXMLは今回repositoryへ追加しない。concrete MusicXMLを後続WBSで生成する場合は、source MIDI identity、source hash、conversion tool、tool version、conversion settings、generated MusicXML hashを記録する。Humanは未確認の権利・license・provenance事項を許可済みとは扱っていない。

# 証跡

Human判断:

1. `Maple Leaf Rag`をprototype曲として選択。
2. `Mutopia-2011/11/13-23`をsourceとして使用。
3. まずGame Boy向け自動編曲prototypeを検証。
4. 十分な品質の場合はプレイ中BGM候補とする。
5. prototypeでは`Mutopia MIDI → MusicXML`を許容。
6. source/converted MusicXMLのrepository保存はconcrete MusicXML生成とprovenance確認後に決定。
7. 現時点はURL/version/hash/conversion procedureを保持。
8. JSON/UGE/ASM/ROM生成をprototypeとして許容。
9. 公開・商用利用は01690の条件を継承。
10. 未確認事項は許可済みとしない。

権利・source調査の根拠と未解決事項は`docs/generated-pd-prototype-rights-provenance-investigation.md`のMaple Leaf Rag sectionに記録した。
