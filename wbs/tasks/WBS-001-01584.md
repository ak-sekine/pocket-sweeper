# 目的

01580のCompositionStructureを共通timelineとして、physical channelへ固定されないNoise/percussion logical layerをseed再現可能に生成する。
# 作業内容

Noise pattern definition/instance、Noise event、rhythmic role、caller-defined character、accent、rest、phrase reference、exact variationを実装する。通常pitchやCH4 hardware parameterは扱わず、logical layerとphysical allocationを分離する。
# 入力

01579のGenerationContext、01580のCompositionStructure、01576のlogical layer model、CH4 Noise/rhythm調査、hardware/tool仕様。
# 成果物

`tools/bgm_generator.py`のlogical Noise/percussion model/generator、`tests/test_bgm_generator.py`の再現性・検証テスト、`docs/generated-noise-percussion-layer.md`。
# 完了条件

同一context呼び出し順・同一structure・同一parameters/options・同一seedで同じNoise layerを生成し、通常pitchなし、pattern/phrase/event参照、role/character/rest整合、範囲、duration、overlap、serializationを機械検証できる。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Git履歴で、初回移行時の「CH4リズム」は旧WBS文言の引き継ぎであり、現行01576のNoise/percussion logical layer原則と一致しないことを確認したため、タイトルをlogical layer表現へ整理した。Noise layerは01581〜01583を入力必須とせず、依存はGenerationContextを提供する01579とCompositionStructureを提供する01580に限定した。

`NoisePatternDefinition`、`NoisePatternInstance`、`NoiseEvent`、`NoiseLayer`を実装した。通常pitch・NR43・LFSR・CH4は保持せず、role/character/accentをlogical metadataとして扱った。初版variationはexactのみ、phrase末尾rest、single logical voice overlap検証とした。CH4 allocation、SFX共存、Human evaluationは実施していない。
