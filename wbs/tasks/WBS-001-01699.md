# 目的

NormalizedScoreからArrangementPlanへのmelody、bass、harmony/accompaniment抽出を検証する。

# 作業内容

role assignment、source event reference、channel allocation、contour、event countを比較し、推定と保持を分離する。

# 入力

01698の比較結果とprototypeのArrangementPlan。

# 成果物

role extraction比較reportと未確認事項。

# 完了条件

各logical roleの選択・除外・変換をsource event単位で説明できる。

# 完了にしてはいけない条件

melodyやbassの正しさを聴感なしに確定しない。

# 確認結果

承認済みsourceをhash検証し、01698のupstream diagnostic hashをsidecarとして参照した。NormalizedScore 2566 eventsはrole assignment上、P2 1193件をmelody、P3 1373件をbassへ割り当て、harmony/accompanimentとrhythmは0件だった。ArrangementPlan出力は31件、omitted 2535件、transformed 11件、rejected 0件で、source_event_id単位のrole/channel/reasonを記録した。role extractionはfull normalized source scopeで行われ、64-row JSON windowは未適用である。Humanの音楽的正しさや01698 onset mismatchの原因は判定していない。

# 証跡

role mapping、event-level diagnostic、比較report、hash、実行command、unit testを`docs/generated-pd-maple-leaf-rag-role-extraction.md`へ記録した。
