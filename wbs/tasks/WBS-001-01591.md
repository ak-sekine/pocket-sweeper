# 目的

caller-owned profileとmaster seedから、既存のlogical generation、JSON Version 2、UGE解析、hUGEDriver ASM、RGBDS確認用ROMを1回のCLI invocationで接続する。
# 作業内容

`tools/generate_bgm_test_rom.py`を追加し、`build_profile(seed)`を提供するPython profileから入力を受ける。既存APIを再利用し、01569の`analyze_uge.read_file()`をROM化前に必須実行する。生成物とSHA-256をmanifestへ記録し、本体BGM/ROMを上書きしない。
# 入力

master seed、`LogicalGenerationPlan`、allocation、resolution、instrument、timing、profile、output name/path。
# 成果物

一括CLI、明示的評価fixture、JSON/UGE/ASM/ROM/manifest artifacts、UGE解析・RGBDS integration。
# 完了条件

1回のCLIでlogical generation→JSON→UGE検証→ASM→ROMが成功し、同一seed/profileでartifact hashesが一致する。既存converter/builderを再利用し、品質評価やSameBoy起動を行わない。
# 完了にしてはいけない条件

SameBoy、実機、試聴、hUGETracker、音楽品質、SFX共存を確認済みと扱わない。
# 確認結果

01569の正本`analyze_uge.read_file()`を確認し、生成UGEをROM化前にSong Version 6とorder alignmentにより解析するpipelineへ組み込んだ。caller-owned Python profileを必須にしてseedだけの根拠なしdefaultを作らなかった。seed 42でJSON→UGE→analyzer→ASM→RGBDS ROMを実行し、別outputへ再実行してJSON/UGE/ASM/ROM SHA-256が一致した。profileは評価fixtureでありproduction作曲profileではない。01592/01593、Human evaluation、SameBoyは後続へ残した。
# 証跡

`docs/generated-song-end-to-end-pipeline.md`、`tools/generate_bgm_test_rom.py`、`tools/generation_profile_fixture.py`、pipeline integration証跡。
