# 目的

pipeline fixtureとは分離した、Humanが音楽評価を行うための明示的なgeneration profileを作成する。

# 作業内容

01673で定義した条件と既存evidence-backed ruleだけを使用し、logical layer、allocation、resolutionを明示したprofileを作成する。production defaultや「良い曲を生成するprofile」とは扱わない。

# 入力

01673の要件、既存logical generator、変換pipeline。

# 成果物

評価用profile、必要な専用テスト。

# 完了条件

profileが再現可能で、入力不足をsilent fallbackせず、既存fixtureを壊さない。

# 完了にしてはいけない条件

根拠のないnote数、tempo、layer必須性、音楽品質defaultを追加した場合は完了にしない。

# 確認結果

評価専用の`tools/generation_profile_quality_evaluation.py`を追加した。melody、accompaniment、bass、noiseの4 logical layerをcoverage目的で明示し、allocation、absolute pitch、pulse/wave/noise instrument、wave table、noise mapping、tempo/TicksPerRowをcaller-owned入力として設定した。既存fixtureは変更していない。JSON Version 2からUGE/ASM/ROMまでのseed 1 smoke validationと、既存全341テストが成功した。

# 証跡

profileのpath、適用rule、machine validation結果、tests/test_bgm_generator.py。
