# 目的

pulse accompaniment / harmonyをCH1・CH2の固定役割にせず、一般音楽理論、Game Boy pulse hardware、4ch/layer制約を接続して、生成・検証可能な設計条件として整理する。
# 作業内容

一般理論、ゲームBGM技法、Game Boy音源制約を分離して調査し、CH2伴奏を固定的な設計パターンとして決めず、生成・検証可能な条件へ整理する。
# 入力

出典付きの調査記録と設計条件。
# 成果物

`docs/game-boy-pulse-accompaniment-harmony-research.md` に、情報源、monophonic pulseでのharmony表現、accompaniment pattern、chord・melody・rhythmとの関係、duty/envelope/register、4ch・SFX共存、自動生成分類、Pocket Sweeperへの適用、未確定事項、後続WBSへの引き継ぎを記録した。
# 完了条件

信頼できる複数資料を確認し、hardware-validとmusically-suitableを分離する。単音pulseでのharmony候補、伴奏pattern、chord・melody・rhythm・pulse音色との関係、4ch制約、SFXによる欠落を整理し、Hard constraint / Soft rule / Parameter / Human evaluation候補を分離する。CH1/CH2の固定役割、具体pattern・音域・duty・密度・default値は決定しない。
# 完了にしてはいけない条件

人による確認が必要な場合、確認結果がない状態で完了にしない。
# 確認結果

Open University、Ithaca College、Fresno State、Berklee、Pan Docsおよび既存仕様・実装を確認した。monophonic pulseによるarpeggio、broken chord、pedal、ostinato、rhythmic chord-tone等を候補として整理し、和声としての知覚、melodyとの適合、duty・envelope・register、SFX欠落時の成立性はHuman evaluationとして分離した。CH1/CH2固定役割、具体的pattern・数値、01563〜01565の詳細は確定していない。試聴・実機・エミュレータ確認は未実施である。旧目的文は現在の役割に合わせて修正した。21曲UGE素材は品質根拠に使用していない。
