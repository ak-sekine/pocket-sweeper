# 目的
full-song JSONを既存pipelineへ接続しROMを生成する。
# 作業内容
UGE、ASM、RGBDS、hash、timing、loopを確認する。
# 入力
01751 artifact。
# 成果物
full-song ROMとprovenance。
# 完了条件
build成功とJSON/UGE note lossの確認。
# 完了にしてはいけない条件
Human評価を代行しない。
# 確認結果
JSON→UGEは成功、ASM生成までは成功した。重複pattern共有後もRGBDS assemblerが`full_song Song Data` sectionの0x4000上限超過（0x84D9）で失敗した。hUGEDriverは16-bit pointerのみでbank番号・bank切替を持たず、sound-test ROMもROM-onlyのため、単純な複数bank配置では再生できない。次工程WBSで設計判断が必要である。
