# 目的

Humanが選択した、source MIDIからgenerated MusicXMLへの音符開始時刻（onset）差分の発生箇所と理由を、再現可能なmachine evidenceで特定する。

# 作業内容

source MIDI、parsed MIDI event representation、MusicXML writer、generated MusicXML、MusicXML parser、NormalizedScore、diagnostic側のabsolute onset復元を段階別に比較する。source_event_id、MIDI PPQ、MusicXML divisions、measure長、measure-local onset、absolute onset、rest・chord・cursor advancement、deltaを記録し、converter defect、diagnostic defect、representation difference、source structureの可能性を分離する。

# 入力

承認済みMutopia Maple Leaf Rag MIDI（source identity: Mutopia-2011/11/13-23、source SHA-256: `3dd712a85fabd267f5a2cee5cb23af4683408c2f29b8814721844498f1ee4f66`）と、01698のdiagnostic evidence（total 2566、onset exact 981、mismatch 1585、最大絶対delta 1152 source ticks）。

# 成果物

onset差分の発生stage、差分規則、未確認事項をsource event単位で追跡できるcomparison reportとmachine-readable evidence。

# 完了条件

1585件のonset差分について、source MIDI onset、generated MusicXML onset、NormalizedScore onset、delta、measure/part/track、変換単位とabsolute onset復元方法を比較し、差分の発生箇所または未確定理由を記録する。

# 完了にしてはいけない条件

差分だけを根拠にconverter defect、diagnostic defect、MusicXML方式の問題、Human試聴結果への因果、改善効果を確定してはならない。原因調査前にwriter/parserやproduction pipelineを変更してはならない。

# 確認結果

承認済みsourceを再生成し、全2566 note eventをsource_event_id単位で比較した。onset mismatchはgenerated MusicXMLの表現とMusicXML parserの2箇所に分かれて観測され、diagnostic absolute reconstruction単独で新たに発生したものではなかった。writer/parserの修正は行っていない。

# 証跡

実測結果を [onset diagnostic report](../../docs/generated-pd-maple-leaf-rag-onset-diagnostic.md) に記録した。source hash、generated MusicXML hash、event-level JSON、実行command、deterministic再実行結果を記録している。Human試聴結果への因果は判定していない。
