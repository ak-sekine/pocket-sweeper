# 目的
原曲構造を保持する統合方式に適したlogical roleとphysical channel割当を検証・実装する。
# 作業内容
role selection、polyphony、melody/bass/harmony/rhythm coverageをsource_event_id単位で比較する。
# 入力
01717設計、01714診断。
# 成果物
role/channel実装と診断。
# 完了条件
選択・除外・割当理由を再現可能に説明できる。
# 完了にしてはいけない条件
machine coverageを音楽的正しさやproduction採用とみなさない。
# 確認結果
P2→melody、P3→bass、harmony/noise=0という既存の明示ruleを統合方式へ引き継ぎ、logical roleとphysical channelを分離した。主旋律の音楽的正しさは判定していない。
# 証跡
